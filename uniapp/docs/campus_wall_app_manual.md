# 校园墙投稿应用使用手册

## 🎉 应用简介

校园墙投稿应用是一款基于uni-app框架开发的微信小程序，旨在为校园社区提供一个信息分享和交流的平台。用户可以在应用中发布校园动态、活动通知、二手交易等内容，管理员可以对投稿进行审核和管理。

小程序码：小程序://校园助手/mPNHIFOLdYQ2Gw

## 📱 功能模块

### 1. 投稿功能

#### 1.1 投稿表单
- **标题输入**：输入投稿的标题（限制50字以内）
- **内容编辑**：支持多行文本输入（限制500字以内）
- **图片上传**：支持上传最多9张图片，可预览和删除
- **标签选择**：可为投稿选择合适的标签，便于分类和检索

#### 1.2 投稿预览
- **内容预览**：实时查看投稿效果
- **背景颜色选择**：支持多种背景颜色设置，美化投稿
- **发布确认**：确认无误后发送投稿，等待审核

### 2. 用户中心

#### 2.1 用户授权
- **头像选择**：使用微信小程序原生头像选择器
- **昵称设置**：可自定义用户昵称
- **授权管理**：管理用户授权信息

#### 2.2 个人中心页面
- **用户信息展示**：显示用户头像、昵称等基本信息
- **功能菜单**：包含我的投稿、我的收藏、设置等功能入口

### 3. 投稿管理

#### 3.1 投稿列表
- **状态分类**：支持待审核/未通过/已审核三种状态的切换
- **批量操作**：支持批量审核、删除等操作
- **搜索筛选**：按关键词、时间等条件筛选投稿

#### 3.2 墙主设置
- **二维码分享**：生成并分享墙面专属二维码
- **短链生成**：生成便于分享的短链接
- **通知管理**：设置审核结果通知等

## 💡 使用流程

### 用户投稿流程
1. 进入应用首页，点击"我要投稿"按钮
2. 填写投稿表单（标题、内容、上传图片、选择标签）
3. 点击"预览"进入预览页面
4. 选择背景颜色，确认投稿内容
5. 点击"确认发布"提交投稿
6. 等待管理员审核，审核结果将通过通知推送

### 管理员审核流程
1. 进入管理页面，查看待审核投稿列表
2. 点击投稿查看详情
3. 选择"通过"或"拒绝"操作
4. 填写审核意见（可选）
5. 确认审核结果，系统自动通知投稿用户

## 🛠️ 技术实现

校园墙投稿应用基于uni-app框架开发，采用组件化、模块化的设计理念，主要技术特点包括：

1. **前端框架**：使用uni-app实现多端兼容
2. **UI组件**：采用uView UI组件库，提供统一的界面风格
3. **数据存储**：结合云存储和本地缓存，优化用户体验
4. **权限管理**：实现基于角色的权限控制系统

## 📋 数据库设计

### 用户表(user)
- user_id：用户ID（主键）
- openid：微信openid
- nickname：用户昵称
- avatar：头像URL
- create_time：创建时间
- update_time：更新时间
- role：用户角色（普通用户/管理员）

### 投稿表(post)
- post_id：投稿ID（主键）
- user_id：用户ID（外键）
- title：标题
- content：内容
- images：图片URL数组
- tags：标签数组
- bg_color：背景颜色
- status：状态（0待审核/1已通过/-1未通过）
- create_time：创建时间
- update_time：更新时间
- review_time：审核时间
- review_comment：审核意见

### 标签表(tag)
- tag_id：标签ID（主键）
- tag_name：标签名称
- create_time：创建时间
- use_count：使用次数
